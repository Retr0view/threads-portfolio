- **Consolidate all resize listeners immediately**: not worth a standalone plan at four carousels; measured image transfer and interaction defects have higher leverage. Reconsider if resize profiling remains hot after Plans 005–007.
- **Remove 4K image device sizes preemptively**: rejected without request/transfer evidence because Next generates optimized variants on demand. Plan 012 measures actual LCP/request priority first.
- **Treat every production-audit advisory as runtime-reachable**: rejected. Plan 003 prioritizes App Router/RSC/image paths actually used and requires explicit reachability analysis for any remainder.
